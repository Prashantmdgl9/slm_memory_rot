# Datasets

The benchmark datasets are **not redistributed** here (size + licensing). Download
them into this directory before running the experiments.

## LongMemEval

- Source: https://github.com/xiaowu0162/LongMemEval
- File needed: `longmemeval_s.json` (the LongMemEval-S split).
- Place it at `data/longmemeval_s.json`.

## LoCoMo

- Source: https://github.com/snap-research/locomo  (license: CC BY-NC 4.0)
- File needed: `data/locomo10.json`.
- Place it at `data/locomo10.json`.

The controlled injection stream used in Phase 2 is **generated in-repo** by
`src/diagnostic/injection.py` — no external download required.
